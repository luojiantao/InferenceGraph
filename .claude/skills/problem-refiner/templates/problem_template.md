## 5W2H 检查清单

在提交问题前，检查以下维度：

- [ ] **What** - 具体是什么现象/需求？（不含模糊词）
- [ ] **Where** - 发生在哪个具体位置？（路径/模块/文件）
- [ ] **When** - 什么时候发生？（触发条件/时间规律）
- [ ] **Who** - 涉及哪些对象？（组件/用户/系统）
- [ ] **Why** - 为什么重要？（业务价值/影响）
- [ ] **How** - 如何复现/实现？（步骤/方案）
- [ ] **How Much** - 量化指标？（数值/目标/范围）

## 模糊词替换对照表

| 模糊词 | 替换为 |
|-------|-------|
| 很慢 | 具体耗时数值 + 对比基准 |
| 有时 | 发生频率/概率 + 触发条件 |
| 很多 | 具体数量 + 统计维度 |
| 异常 | 具体错误码/现象/日志 |
| 优化 | 明确的优化目标和衡量指标 |
| 频繁 | 具体次数/单位时间 |
| 大部分 | 具体百分比 + 样本量 |
| 可能 | 确认的事实或标记为待确认 |
| 应该 | 实际观察到的行为 |
| 无法使用 | 具体功能 + 具体现象 |
